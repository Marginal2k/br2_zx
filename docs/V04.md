# BR2D004: устройство демо v0.04 (Human && Kunge Action)

Источник: `reference/zxart/x_BR2D004/BR2D004.SCL`. Сборка датирована маем 1999 - апрелем 2000 (`FILE_ID.DIZ`, текст автора `BR2DEM04.txt`).
Инструменты: `tools/match_v04.py [hum|kun]` (сопоставление с исходниками), `tools/v04dis.py` (дизассемблер страниц). Выводы лежат в `build/match_*`; страницы и загрузчики извлечены в `work/v04/`.

## Состав

На диске две независимые кампании, каждая — отдельный образ 128K (8 страниц по 16384 байт):
* люди: BASIC `BR2HUM04` + файлы `br2hum04.0..7`;
* кунги: BASIC `BR2KUN04` + файлы `br2kun04.0..7`.

Во время игры диск не используется. Дисковый код (`D_READ`, `READ`, `LODlev`) остался в образе, но не вызывается.

## Загрузка

1. BASIC (242 байта, строка 1) вызывает машинный код в `#5D49`.
2. Загрузчик через ПЗУ TR-DOS (`#2F1B`) читает по 64 сектора на страницу в `#C000`. Порядок страниц: 0,1,2,3,4,6,7,5 (порт `#7FFD` = `#10|n`).
3. Затем ставит регистры и переходит на `JP #4023` (`JP_ST`).

## Что внутри

* Код — наша база (`4.Z80` от 17.11.1999) с мелкими правками.
* Вход `_wMAIN: JP #4E8D`, дальше `putBAR`, `setMAP`, `_start`. Это отладочный вход: **меню и демо не вызываются**. Код меню (`menu2.asm`) в образе есть и совпадает с исходником.
* Чем отличаются кампании:

| | люди (hum) | кунги (kun) |
|---|---|---|
| Ландшафт | `45SPR` | `44SPR` |
| Кнопки | `4H_BUTT` | `4K_BUTT` |
| Карта | `MAP/4_10.MAP` (совпадение 99,8 %) | в архиве нет, только в образе: стр. 2 `#8000`, 4353 байта |

* Музыка у обеих — `SONG1C`. Шрифт = новый `4FONT.FNT` (отличается на 3 байта).
* Сохранение и загрузка не работают: `G_DATA` = 0, длина 0.
* Прерывания: I=`#41`, таблица `#4100` (257×`#40`), `JP INTRP (#7423)` на `#4040`. Всё в странице 5, отсюда снег.

## Защиты и мёртвый код

* `PROTeC` удалён: на его месте `CALL 0` (`#58DF`).
* Вызовы `INI_D2`/`LOD1st` заменены на `CALL 0` (`#4CBE`, `#4CC1`). Ещё два `CALL 0` в стр. 6 (`#C3F4`, `#C47C`) — достижимость проверить в эмуляторе.
* `antiTM` при срабатывании пишет `#CCCC` в `#A021`.
* `chkCRC`, `ENCODE`/`DECODE` на месте.

## Сопоставление с исходниками

* Совпадает 51 % ненулевых байт образа hum. В кодовых страницах 0/5/7 — около 85 %.
* Не объяснено исходниками около 12 КБ кода (сотни мелких правок) плюс данные уровня и ландшафта.
* Сдвиги адресов: стр. 0 на +1, стр. 5 на -`#2A`..-`#72`, остальные страницы без сдвига.

## Прочие релизы

`BR2D000` (v0.00) и `BR2DM001` (v0.01) — ранние образы, упакованные Hrust. Для воссоздания v0.04 не нужны; из них пригодны тексты инструкции и заставки.
