# BR2D004: реконструкция исходников (фаза 2b-1, промежуточное состояние)

## Итог на сейчас

* **Люди (HUM).** Сборка `work/src_v04/hum` даёт 8 страниц, побайтно равных `work/v04/br2hum04.N.bin`. Исключение — 123 байта DEFR/UNDEF в странице 5 (мусор памяти ассемблера). `python -I tools/verify_v04.py hum` → UNEXPLAINED 0.
* **Кунги (KUN).** Страницы 0, 1, 3, 4, 6 совпадают. Страницы 5, 2, 7 расходятся (27213 байт): образ снят из эмулятора, в нём живое состояние, стек и экран.
* **Исходник пока НЕ годится как итоговый:**
  - 908 строк переписаны на абсолютные адреса (`; v0.04 (was: ...)`);
  - 35 меток вида `v4_XXXX`;
  - 667 служебных проверок `CHK_`.

## Метод

* База — исходник `4.Z80` (17.11.1999).
* `tools/mkv04.py` выравнивает записи сборки с v0.04. `tools/mkv04_gen.py` пишет дерево: совпавшее остаётся строками автора, изменённое или новое дизассемблируется, данные подключаются через INCBIN (файлы архива, а если их нет — куски образа в `work/assets_v04/<сторона>`).

## Ресурсы v0.04 новее архива

KAPELL, KING, ZERG, VARLOK, MISC2X2, MISC3X3, NAMES, ~SHADOW, SONG1C, карта `4_10.MAP` (совпадает на 99,8 %). Их берём из образа.

## Меню, демо, сохранение

* **Меню.** Стартового меню в исходниках нет. Есть только меню паузы `M_MENU` (6 пунктов). `LDI123` нигде не определён.
* **Демо.** Есть только в `_OLD/__DEMO.A80`: заставка со случайным боем, не запись игры. В 4.Z80 и v0.04 его нет.
* **Сохранение.** `SAVgam`/`ENCODE` работают с адресом 0 и длиной 0. Пункт загрузки делает `JP qLOAD`, а `qLOAD` равен 0, то есть сброс.
* **INI_D2/LOD1st.** По смыслу: выбор дисковода диска 2 и чтение таблицы файлов. Будут заменены дисковым слоем.

## CALL 0

`#4CBE`, `#4CC1` (INI_D2, LOD1st), `#58DF` (PROTeC), `#C3F4` и `#C47C` (стр. 6). Последние два, вероятно, достижимы — проверить в эмуляторе.

## Состояние 2b-1 (символьность)

* Дерево `work/src_v04/game` одно на обе стороны (`-DKUN=1` выбирает кунгов).
* **Люди (HUM):** собирается в образ, равный v0.04, кроме DEFR/UNDEF (123 байта). `tools/verify_v04.py hum` → UNEXPLAINED 0.
* **Перемещаемость:** `tools/check_reloc.py hum 16` → OK. Код сдвигается на 16 байт в стр. 0 и в стр. 5 после таблицы IM2, проверено 4400 операндов.
* **Пометки:** рабочих пометок (CHK_, was:) нет.
* **Числа вместо меток:** осталось 41 числовой операнд >= `#4000`:

| Что | Сколько |
|---|---|
| Порты | 17 |
| Системные переменные ПЗУ | 2 |
| Константы экрана | 3 |
| Прочие (данные, координаты, длины) | 19 |

* **Новые участки:** 237 новых или изменённых участков помечены заголовками; внутренние метки названы `v4_<метка>_<n>`.

### Кунги (KUN)

С `-DKUN` пока UNEXPLAINED 31408. Причины:
* таблица CALL_ в `_start` длиннее на одно слово, поэтому всё в стр. 5 после неё сдвинуто на +2;
* другие данные уровня;
* живое состояние снимка: стек `#401C-#403E`, экран стр. 7, переменные.

### Демо (`__DEMO.A80`)

Из 33 внешних символов не хватает трёх: `ANIset`, `IX_93`, `makTRY`.
