# Проверки в эмуляторе (ZX-M8XXX, headless Chrome)

Нужны:
* эмулятор ZX-M8XXX — путь к нему задаётся переменной `M8XXX_DIR`;
* Python и Pillow;
* Chrome (другой браузер — переменная `EDGE=...`).

Каждый запуск поднимает свой сервер (`serve_emu.py`, порт `EMU_PORT`, по умолчанию 8851) и headless-браузер. **Два запуска одновременно не делать.**
На занятой машине страница иногда не успевает стартовать — тогда `run_emu.py` сам повторяет запуск. Один запуск идёт 25–60 с.

```
python tools/emu/run_emu.py play name=t trd=br2_game.trd steps=@boot                                   # build/br2_game.trd, Pentagon; сценарий scen/boot.txt
python tools/emu/run_emu.py play name=t trd=br2_game.trd machine=128k beta=1 snow=1 "steps=boot,w600,Kx,w150,K1,w400,c:hum"   # Sinclair 128K со «снегом»: игра за людей
python tools/emu/run_emu.py play name=t trd=br2_intro.trd machine=128k beta=1 steps=@readme_d1          # прощальный диск: заставка и ролики
python tools/emu/run_emu.py play name=t trd=br2_1mb.trd steps=@soak                                     # долгий прогон игры
```

Имена в `trd=` берутся из `build/`. Сценарий `@имя` — файл `scen/имя.txt`.

**Результат:**
* `build/emu/<name>.json` — лог, регистры, дампы памяти `mem`, образы дисков `disks`;
* `build/emu/<name>_<снимок>.png` — снимки: `c:имя` — экран эмулятора с рамкой (и снегом, если он есть), `s:имя` — только экран из ОЗУ.

Лог печатается в консоль.

**Шаги сценария** (через запятую или по строкам; `#` — комментарий). Полный список — в начале `scripts/play.js`.

| Шаг | Что делает |
|---|---|
| `boot` | сброс и `RUN` |
| `wN` | ждать N кадров |
| `Kx` | держать клавишу 70 кадров (меню опрашивают редко) |
| `hx:N:M` | держать клавишу N кадров |
| `kx` | короткое нажатие |
| `dx` / `ux` | нажать / отпустить |
| `c:имя` / `s:имя` | снимок |
| `m:имя:ADDR:LEN` | дамп памяти |
| `pADDR:VV` | записать байт в память |
| `ins:N:файл.trd` | вставить диск в дисковод N |
| `rt:ADDR:MAXFR` | идти до PC=ADDR |

**Игра в сценариях:**
* С диска игры: `boot`, `w600`, `Kx` (пропустить демо), затем `K1` — люди, `K2` — кунги, `K3` — загрузка.
* Курсор: `hQ`/`hA`/`hO`/`hP`. Выделение: `dCAPS`…`uCAPS`. Приказ: `kSpace`.
* Позиции бойцов лежат с `#7680` (люди) и `#7B00` (кунги), по 24 байта на бойца, первые два байта — x, y.
  Пример проверки «бойцы ходят»: `scen/lead_genmove.txt`.

**Про эмулятор:**
* Снег: в эмуляторе есть (`snow=1`). На Pentagon снега не бывает. Для `128k` и `+2` нужен `beta=1`, иначе нет TR-DOS.
* Писать в ОЗУ эмулятора надо **без `await` между записями**, иначе цикл эмулятора успевает пробежать и затереть банки.
